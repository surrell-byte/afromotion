# Afromotion

Static HTML, CSS and JavaScript site for Afromotion.

## View locally

From this directory, run:

```sh
python3 -m http.server 8000
```

Then open <http://localhost:8000>.

## GitHub Pages

The `main` branch is deployed to GitHub Pages by the workflow in
`.github/workflows/pages.yml` whenever changes are pushed. The live URL is:

<https://surrell-byte.github.io/afromotion/>
